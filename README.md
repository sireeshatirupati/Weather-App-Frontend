# 🌦️ Weather App - Frontend Project

🔴 **Live Demo:** https://sireeshatirupati.github.io/Weather---App---Frontend-/

A simple and responsive weather app that shows live weather for any city.

### ✨ Features
- Search any city weather
- Shows Temperature, Humidity, Wind
- Works on Mobile & Laptop
- No API key needed

### 🛠️ Built With
- HTML5, CSS3, JavaScript
- Free Weather API (wttr.in)
- Hosted on GitHub Pages
